> **[`codexstar69/pi-listen`](https://github.com/codexstar69/pi-listen) का कम्युनिटी-संचालित उत्तराधिकारी** (अपस्ट्रीम, MIT — मई 2026 में v7.2.2 के बाद निष्क्रिय)।

एजेंट के जवाब बोलकर सुनाता है (Kitten, Kokoro, Piper, या Deepgram Aura)।

## सेटअप (2 मिनट)

### 1. एक्सटेंशन इंस्टॉल करें

```bash
# सामान्य टर्मिनल में चलाएँ (Pi के अंदर नहीं)
pi install npm:pi-voicekit
```

### 2. अपना बैकएंड चुनें

pi-voicekit दो ट्रांसक्रिप्शन बैकएंड सपोर्ट करता है:

|                      | Deepgram (क्लाउड)                                                | लोकल मॉडल (ऑफ़लाइन)                                         |
| -------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------- |
| **कैसे काम करता है** | लाइव स्ट्रीमिंग — बोलते समय टेक्स्ट दिखता है                     | बैच मोड — रिकॉर्डिंग पूरी होने के बाद ट्रांसक्राइब करता है  |
| **सेटअप**            | API कुंजी ज़रूरी                                                 | कोई API कुंजी नहीं, मॉडल पहले उपयोग पर ऑटो-डाउनलोड होते हैं |
| **इंटरनेट**          | ज़रूरी                                                           | मॉडल डाउनलोड के बाद ज़रूरी नहीं                             |
| **लेटेंसी**          | रियल-टाइम अंतरिम परिणाम                                         | रिकॉर्डिंग रुकने के बाद 2–10 सेकंड                          |
| **भाषाएँ**           | लाइव स्ट्रीमिंग के साथ 56+                                        | मॉडल पर निर्भर (1–57 भाषाएँ)                                |
| **लागत**             | $200 मुफ़्त क्रेडिट (अधिकांश डेवलपर्स के लिए 6–12 महीने चलता है)  | हमेशा मुफ़्त                                                |

Pi के अंदर `/voice-settings` चलाएँ — बैकएंड चुनें और सब कुछ एक ही पैनल से कॉन्फ़िगर करें।

#### विकल्प A: Deepgram (लाइव स्ट्रीमिंग के लिए अनुशंसित)

[dpgr.am/pi-voice](https://dpgr.am/pi-voice) पर साइन अप करें — $200 मुफ़्त क्रेडिट, कार्ड की ज़रूरत नहीं।

```bash
export DEEPGRAM_API_KEY="your-key-here"    # ~/.zshrc या ~/.bashrc में जोड़ें
```

#### विकल्प B: लोकल मॉडल (पूरी तरह ऑफ़लाइन)

कोई सेटअप ज़रूरी नहीं — `/voice-settings` चलाएँ, बैकएंड को Local पर स्विच करें और मॉडल चुनें। यह अपने आप डाउनलोड हो जाएगा।

> **नोट:** लोकल मॉडल बैच मोड में काम करते हैं — वे बोलते समय नहीं, बल्कि रिकॉर्डिंग पूरी होने के बाद ट्रांसक्राइब करते हैं। बोलते ही लाइव स्ट्रीमिंग के लिए Deepgram का उपयोग करें।

### 3. Pi खोलें

पहली बार शुरू करने पर pi-voicekit आपका सेटअप जाँचता है और बताता है कि क्या तैयार है:

- बैकएंड कॉन्फ़िगर हो गया (Deepgram कुंजी या लोकल मॉडल)
- ऑडियो कैप्चर टूल मिल गया (sox, ffmpeg, या arecord)
- अगर सब कुछ ठीक है, तो वॉइस तुरंत सक्रिय हो जाता है

### ऑडियो कैप्चर

pi-voicekit आपका ऑडियो टूल ऑटो-डिटेक्ट करता है। अगर आपके पास पहले से sox या ffmpeg है तो मैन्युअल इंस्टॉल की ज़रूरत नहीं।

| प्राथमिकता | टूल             | प्लेटफ़ॉर्म           | इंस्टॉल                                                      |
| ---------- | --------------- | --------------------- | ------------------------------------------------------------ |
| 1          | **SoX** (`rec`) | macOS, Linux, Windows | `brew install sox` / `apt install sox` / `choco install sox` |
| 2          | **ffmpeg**      | macOS, Linux, Windows | `brew install ffmpeg` / `apt install ffmpeg`                 |
| 3          | **arecord**     | केवल Linux            | पहले से इंस्टॉल (ALSA)                                       |

> जब `PULSE_SERVER` सेट होता है (SSH ऑडियो टनल या रिमोट PulseAudio), तो क्रम
> **ffmpeg → sox → arecord** हो जाता है — नेटवर्क Pulse स्रोतों के लिए ffmpeg ज़रूरी है।

## सेटिंग्स पैनल

सारी कॉन्फ़िगरेशन एक ही जगह: `/voice-settings`। पाँच टैब आपकी ज़रूरत का सब कुछ कवर करते हैं।

### सामान्य — बैकएंड, भाषा, स्कोप

<img src="../assets/screenshots/settings-general.png" alt="सामान्य सेटिंग्स — बैकएंड, मॉडल, भाषा, स्कोप, वॉइस टॉगल" width="600" />

Deepgram (क्लाउड, लाइव स्ट्रीमिंग) और Local (ऑफ़लाइन, बैच मोड) के बीच स्विच करें। भाषा, स्कोप बदलें और वॉइस को चालू/बंद करें — सब कीबोर्ड शॉर्टकट से।

### मॉडल — ब्राउज़ करें, खोजें, इंस्टॉल करें

<img src="../assets/screenshots/settings-models.png" alt="मॉडल टैब — सटीकता/गति रेटिंग के साथ 21 मॉडल ब्राउज़ करें" width="600" />

Parakeet, Whisper, Moonshine, SenseVoice, GigaAM, Paraformer और Qwen3 के 21 मॉडल ब्राउज़ करें। हर मॉडल सटीकता और गति रेटिंग (●●●●○/●●●●○), उपयुक्तता बैज और डाउनलोड स्थिति दिखाता है। मॉडल जल्दी ढूँढ़ने के लिए फ़ज़ी सर्च। सक्रिय करने और डाउनलोड करने के लिए Enter दबाएँ।

### डाउनलोड किए गए — इंस्टॉल किए गए मॉडल प्रबंधित करें

<img src="../assets/screenshots/settings-downloaded.png" alt="डाउनलोड किए गए टैब — इंस्टॉल किए गए मॉडल प्रबंधित करें, सक्रिय करें या हटाएँ" width="600" />

देखें कि क्या इंस्टॉल है, कुल डिस्क उपयोग और कौन सा मॉडल सक्रिय है। सक्रिय करने के लिए Enter दबाएँ, हटाने के लिए `x`। [Handy](https://github.com/cjpais/handy) के मॉडल ऑटो-डिटेक्ट होते हैं और बिना दोबारा डाउनलोड किए इम्पोर्ट किए जा सकते हैं।

### बोलें — TTS मॉडल और वॉइस

कोई TTS बैकएंड चुनें (लोकल sherpa-onnx या Deepgram Aura), ~13 MB से शुरू होने वाले
20 लोकल वॉइस ब्राउज़ करें, चुनते ही डाउनलोड करें, और हर बैकएंड के लिए अलग वॉइस चुनें।
एजेंट के जवाबों का ऑटो-स्पीक यहीं टॉगल होता है।

### डिवाइस — हार्डवेयर प्रोफ़ाइल और डिपेंडेंसी

<img src="../assets/screenshots/settings-device.png" alt="डिवाइस टैब — हार्डवेयर प्रोफ़ाइल, डिपेंडेंसी, डिस्क स्पेस" width="600" />

अपनी हार्डवेयर प्रोफ़ाइल (RAM, CPU, GPU), डिपेंडेंसी स्टेटस (sherpa-onnx रनटाइम), उपलब्ध डिस्क स्पेस और कुल डाउनलोड किए गए मॉडल देखें। मॉडल सिफ़ारिशें इसी प्रोफ़ाइल पर आधारित होती हैं।

## उपयोग

### की-बाइंडिंग

| कार्य                      | कुंजी                    | नोट्स                                                                                    |
| -------------------------- | ------------------------ | ---------------------------------------------------------------------------------------- |
| **एडिटर में रिकॉर्ड करें** | `SPACE` दबाए रखें (≥0.7 सेकंड) | छोड़ते ही फ़ाइनल हो जाता है। वॉर्मअप के दौरान प्री-रिकॉर्ड करता है ताकि कोई शब्द न छूटे। |
| **रिकॉर्डिंग टॉगल करें**   | `Ctrl+Shift+V`           | हर टर्मिनल में काम करता है — शुरू करने के लिए दबाएँ, रोकने के लिए फिर दबाएँ।            |
| **एडिटर साफ़ करें**        | `Escape` × 2             | 500ms के भीतर दो बार दबाने पर सारा टेक्स्ट साफ़ हो जाता है।                              |

### रिकॉर्डिंग कैसे काम करती है

1. **SPACE दबाए रखें** — वॉर्मअप काउंटडाउन दिखता है, ऑडियो कैप्चर तुरंत शुरू हो जाता है (प्री-रिकॉर्डिंग)
2. **दबाए रखें** — लाइव ट्रांसक्रिप्शन एडिटर में स्ट्रीम होता है (Deepgram) या ऑडियो बफ़र में जाता है (लोकल)
3. **SPACE छोड़ें** — आपका आख़िरी शब्द पकड़ने के लिए रिकॉर्डिंग 1.5 सेकंड और चलती है (टेल रिकॉर्डिंग), फिर फ़ाइनल होती है
4. टेक्स्ट एडिटर में आ जाता है, भेजने के लिए तैयार

| `/voice-speak-models`    | TTS वॉइस मॉडल ब्राउज़ / इंस्टॉल करें                        |
| `/voice-speak-info`      | TTS स्थिति का डायग्नोस्टिक                                 |
| `/voice-help`            | कीबोर्ड + कमांड संदर्भ (या `F1` दबाएँ)                     |
| `/voice test`            | पूरा डायग्नोस्टिक — ऑडियो टूल, माइक, API कुंजी             |
| `/voice on` / `off`      | वॉइस चालू या बंद करें                                      |
| `/voice dictate`         | लगातार डिक्टेशन (कुंजी दबाए रखने की ज़रूरत नहीं)            |
| `/voice stop`            | सक्रिय रिकॉर्डिंग या डिक्टेशन रोकें                        |
| `/voice history`         | हाल की ट्रांसक्रिप्शन                                      |
| `/voice`                 | चालू/बंद टॉगल                                              |

| -------------------- | ------ | ----- | ------ | ------ | ----------------------------------------- |
| **GigaAM v3**        | ●●●●○  | ●●●●○ | 225 MB | रूसी   | रूसी पर Whisper से 50% कम WER।            |
| **Whisper Medium**   | ●●●●○  | ●●●○○ | 946 MB | 57     | अच्छी सटीकता, मध्यम गति।                  |
| **Whisper Large v3** | ●●●●○  | ●○○○○ | 1.8 GB | 57     | Whisper की सबसे ऊँची सटीकता। CPU पर धीमा। |

इसके अलावा जापानी, कोरियाई, अरबी, चीनी, यूक्रेनी, वियतनामी और स्पेनिश के लिए 8 भाषा-विशेष Moonshine v2 वैरिएंट मौजूद हैं।

### लोकल मॉडल कैसे काम करते हैं

```
SPACE दबाए रखें → ऑडियो मेमोरी बफ़र में कैप्चर होता है
                     ↓
SPACE छोड़ें → बफ़र sherpa-onnx को भेजा जाता है (इन-प्रोसेस)
                     ↓
              CPU पर ONNX इन्फ़रेंस (2–10 सेकंड)
                     ↓
              अंतिम ट्रांसक्रिप्ट एडिटर में डाला जाता है
```

मॉडल पहले उपयोग पर अपने आप डाउनलोड होते हैं। डाउनलोड रिज़्यूम हो सकते हैं, पूरा होने के बाद सत्यापित होते हैं, और डुप्लीकेट नहीं होते (दोबारा डाउनलोड नहीं होता)। सेटिंग्स पैनल में रियल-टाइम डाउनलोड प्रगति, गति और ETA दिखती है।

[Handy](https://github.com/cjpais/handy) (`~/Library/Application Support/com.pais.handy/models/`) के मॉडल ऑटो-डिटेक्ट होते हैं और सिम्लिंक के ज़रिए इम्पोर्ट किए जा सकते हैं (डिस्क पर शून्य डुप्लीकेशन)।

## कॉन्फ़िगरेशन

सेटिंग्स Pi की सेटिंग्स फ़ाइलों में `voice` कुंजी के अंतर्गत संग्रहीत होती हैं:

| स्कोप     | पथ                            |
| --------- | ----------------------------- |
| ग्लोबल    | `~/.pi/agent/settings.json`   |
| प्रोजेक्ट | `<project>/.pi/settings.json` |

```json
{
	"voice": {
		"version": 2,
		"enabled": true,
		"language": "en",
		"backend": "local",
		"localModel": "parakeet-v3",
		"scope": "global",
		"onboarding": { "completed": true, "schemaVersion": 2 }
	}
}
```

आपके शेल का `DEEPGRAM_API_KEY` रनटाइम पर उपयोग होता है और
`~/.pi/agent/settings.json` में वापस नहीं लिखा जाता। अगर आप ऑनबोर्डिंग के दौरान
कोई कुंजी पेस्ट करते हैं, तो वह एक स्पष्ट सेव है और वह भी `~/.env.secrets` या
`~/.zshrc` में जाती है।

होल्ड-टू-टॉक देरी डिफ़ॉल्ट रूप से **700 ms** होती है (`/voice-hold-delay` 200–3000 ms स्वीकार करता है)।

## समस्या निवारण

पूरे डायग्नोस्टिक के लिए Pi के अंदर `/voice test` चलाएँ।

| समस्या                                             | समाधान                                                                                                          |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| "DEEPGRAM_API_KEY not set"                         | [कुंजी प्राप्त करें](https://dpgr.am/pi-voice) → `~/.zshrc` में `export DEEPGRAM_API_KEY="..."` जोड़ें            |
| "No audio capture tool found"                      | `brew install sox` या `brew install ffmpeg`                                                                     |
| रिमोट माइक्रोफ़ोन से सन्नाटा रिकॉर्ड होता है       | PulseAudio/SSH पर ऑडियो — Pi वाली मशीन पर ffmpeg इंस्टॉल करें (तब कैप्चर ffmpeg को प्राथमिकता देता है)          |
| स्पेस से वॉइस सक्रिय नहीं होता                      | `/voice-settings` चलाएँ — वॉइस बंद हो सकता है                                                                    |
| लोकल मॉडल ट्रांसक्राइब नहीं कर रहा                  | `/voice-settings` → डिवाइस टैब में sherpa-onnx की स्थिति जाँचें                                                  |
| डाउनलोड विफल                                        | आंशिक डाउनलोड दोबारा प्रयास पर अपने आप रिज़्यूम होते हैं। डिवाइस टैब में डिस्क स्पेस जाँचें।                      |
| macOS पर `dyld: Library not loaded: libsimdjson`   | Homebrew Node का ABI मेल नहीं खाता — `brew reinstall node` चलाएँ, या वर्ज़न-मैनेज्ड Node (`mise`, `fnm`, `nvm`) पर स्विच करें |

## सुरक्षा

- **क्लाउड STT** — ट्रांसक्रिप्शन के लिए ऑडियो Deepgram को भेजा जाता है (केवल Deepgram बैकएंड)
- **लोकल STT** — ऑडियो आपकी मशीन से बाहर कभी नहीं जाता (लोकल बैकएंड)
- **कोई टेलीमेट्री नहीं** — pi-voicekit उपयोग डेटा एकत्र या प्रसारित नहीं करता
- **API कुंजी** — एनवायरनमेंट वेरिएबल या Pi सेटिंग्स में संग्रहीत, कभी लॉग नहीं होती
